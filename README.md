## 🚀 Proyectos

### 1. Sistema web para la gestión de mascotas y citas veterinarias
Facilita la gestión de mascotas y su información veterinaria: permite registrar propietarios, programar citas, guardar las atenciones realizadas y consultar el historial médico de cada mascota.

**Tecnologías:** HTML, CSS, Python

![Captura del proyecto 1](img/proyecto1.jpg)

### 2. Plataforma web de administración de matrículas universitarias
Plataforma de gestión académica. Los estudiantes inician sesión de forma segura, gestionan sus materias, consultan sus notas y ven su horario de clases. El módulo administrativo permite crear y gestionar materias, administrar la información académica y generar reportes con gráficos de barras.

**Tecnologías:** HTML, Python, MySQL

![Captura del proyecto 2](img/proyecto2.jpg)

### 3. Sistema de administración de parqueadero
Sistema para gestionar y controlar un parqueadero. Registra la hora de entrada y salida de los vehículos y los datos del propietario, y calcula automáticamente el valor del servicio según el tipo de vehículo y el tiempo de permanencia.

**Tecnologías:** Python, MySQL

![Captura del proyecto 3](img/proyecto3.jpg)

## 💻 Cómo verlo en tu computador

1. Clona el repositorio:
   ```bash
   git clone https://github.com/DJdanny18/Zynova.git
   ```
2. Abre el archivo `index.html` en tu navegador.

---

## 🌐 Publicación con GitHub Pages

1. Ve a **Settings → Pages** en el repositorio.
2. En **Source**, elige la rama `main` y la carpeta `/ (root)`.
3. Guarda. En unos minutos la página estará disponible en la URL indicada arriba.
